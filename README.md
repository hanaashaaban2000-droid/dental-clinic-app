🦷 Harmony Clinic Website

A modern, responsive Dental Clinic website built with React.js. The project focuses on creating a clean user interface, smooth navigation, multilingual support, and optimized performance to deliver a better user experience.

⚙️ Installation

Clone the repository

git clone https://hanaashaaban2000-droid.github.io/dental-clinic-app/

Go to the project directory

cd dental-clinic-react

Install dependencies

npm install

Start the development server

npm start
